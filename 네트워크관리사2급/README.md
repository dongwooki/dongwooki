# 네트워크관리사 2급 필기 — 벼락치기 공부노트

> 네트워크를 처음 공부하는 사람이 **공부노트 → 핵심사항 → 연습문제 → 최근 기출 CBT → 모의고사** 순서로 합격선까지 빠르게 도달하도록 만든 자료입니다.
> 연습문제와 모의고사는 ICQA **과거 기출에 자주 나온 개념과 유형을 바꿔 새로 만든 문제**입니다(CBT 사이트의 문제를 그대로 옮기지 않았습니다). **최근 회차는 CBT 사이트(comcbt, cbtbank, sqldpass)에서 실전 연습용으로 풀도록 남겨 두었습니다.**

---

## 1. 시험 개요 (2026년 10월 27일 기준, ICQA 종목 안내·sqldpass 시험 정보)

| 항목 | 내용 |
|---|---|
| 주관 | 한국정보통신자격협회(ICQA) |
| 필기 형식 | 50문항, 4지 택일형, CBT(컴퓨터 시험) |
| 시험 시간 | 50분 |
| 합격 기준 | 100점 만점에 60점 이상(**50문항 중 30문항 이상 정답**), **과목별 과락 없음** |
| 다음 시험 | **2026년 11월 1일** (정기 시험은 해마다 4회, 대개 2월·5월·8월·11월) |

| 과목 | 문항 수 | 비중 | 해당 노트 |
|---|---|---|---|
| TCP/IP | 17 | 34% | 02, 03 |
| 네트워크 일반 (보안 기초 포함) | 10 | 20% | 01, 07 |
| NOS (Windows Server + Linux) | 18 | 36% | 04, 05 |
| 네트워크 운용기기 | 5 | 10% | 06 |

**합격 전략:** 과락이 없으므로 **TCP/IP와 NOS(35문항, 70%)** 에서 점수를 확보하세요. 서브넷팅 계산, 포트 번호, 리눅스 권한·명령어처럼 **외워 두면 확실히 맞히는 문제**부터 챙기고, 처음 보는 문제는 과감히 찍고 넘어갑니다. 운용기기는 5문항뿐이니 06 노트는 ★ 핵심사항 위주로 빠르게 봐도 됩니다.

### 노트 구성 (01~07 공통)
1. **본문** — 처음 공부하는 사람도 "왜 그런지"까지 이해할 수 있게 설명하고, 절마다 `💡 시험 포인트`로 마무리합니다.
2. **★ 핵심사항** — 시험 직전 10분 동안 훑어볼 암기 목록
3. **⚠️ 헷갈리는 함정 포인트** — 오답 보기로 자주 나오는 비교 짝
4. **🧠 암기 팁** — 앞 글자 따기, 연상법
5. **📝 연습문제 25문항** — 과거 기출 유형을 바꾼 문제 (노트끼리 겹치지 않음)
6. **✅ 정답 및 해설** — 오답 보기가 왜 틀렸는지까지 설명

> 연습문제는 **정답을 가리고** 먼저 풀어 보고, 틀린 문제는 문항 번호(예: `[IP-07]`)와 함께 오답노트에 적어 두세요.

## 4. 최근 기출은 몇 년 치를 남겨 둘까? → **최근 2년(8회분) 추천**

정기 시험이 해마다 4회 정도라서 2년 치는 약 8회분입니다.

| 상황 | 남겨 둘 회차 | 이유 |
|---|---|---|
| **기본(추천)** | **최근 2년, 8회분** | 최신 출제 경향과 반복 출제 문제를 충분히 확인하면서도 1~2일이면 다 풀 수 있는 양 |
| 시간이 정말 없을 때 | 최근 1년, 4회분 | 최신 경향만이라도 확인 |
| 시간이 넉넉할 때 | 최근 3년, 12회분 | 3년 전 회차는 복습용으로 빠르게 |

이 자료의 연습문제와 모의고사는 **그보다 오래된 기출 유형을 바꿔 만든 문제**라서, CBT용으로 남겨 둔 최근 회차를 미리 보게 되는 일이 없습니다.

- 찾아가는 곳: comcbt는 회차별 게시글의 **CBT** 버튼, cbtbank는 `cbtbank.kr/category/네트워크관리사-2급`, sqldpass(문어CBT)는 `sqldpass.com/past-exams?cert=NETWORK_ADMIN_2`

### ⚠️ 사이트 3곳을 쓸 때 주의 — "회차 기준"으로 나누세요
세 사이트는 **같은 ICQA 기출 회차를 각각 싣고 있어서**(위 표), 사이트만 바꿔 같은 회차를 풀면 결국 같은 문제를 두 번 풀게 됩니다. 사이트가 아니라 **회차(시행일)** 를 기준으로 나눠 푸세요.

| 단계 | 회차 | 푸는 방법 |
|---|---|---|
| CBT 1차 (D-2) | 1~4번 (2024-11 ~ 2025-08) | sqldpass나 cbtbank에서 50분 타이머를 맞추고 풀기 → 채점 후 해설 확인 |
| CBT 2차 (D-1 오전) | 5~8번 (2025-11 ~ 2026-08) | 2025-11 회차는 아무 사이트에서나, **2026년 3회분은 comcbt CBT**로 |
| 모의고사 (D-1 저녁) | [08 최종 모의고사](08_최종모의고사.md) | 연습문제·최근 기출과 겹치지 않는 50문항 |
| 랜덤·오답 모드 | 시험 당일 아침 | sqldpass의 오답노트·오답률 TOP 30, cbtbank의 랜덤 출력은 **이미 푼 회차의 오답 복습용**으로만 |

> 그보다 오래된 회차(2021년 ~ 2024년 상반기)는 시간이 남을 때 **추가 연습용**으로만 쓰세요. 이 자료의 연습문제와 다루는 개념이 겹칠 수 있습니다.

> **CBT 점수 보는 법:** 최근 회차 CBT에서 **70점 이상이 두 번 연속** 나오면 합격권입니다. 60점대라면 틀린 개념을 노트 본문에서 다시 보강하세요.
