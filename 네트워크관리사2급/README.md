# 네트워크관리사 2급 필기 — 벼락치기 공부노트

> 처음 공부하는 사람이 **공부노트 → 핵심사항 → 연습문제 → CBT(최근 기출) → 모의고사** 순서로 바로 합격선까지 가기 위한 자료입니다.
> CBT 사이트: comcbt(전자문제집 CBT), cbtbank, sqldpass — 연습문제·모의고사는 ICQA **과거 기출의 빈출 개념·유형을 변형**해서 새로 만든 문제이고(사이트 문제를 그대로 옮긴 것 아님), **최근 회차는 위 사이트에서 CBT 실전용으로 풀도록 남겨 두는** 구성입니다.

---

## 1. 시험 개요 (응시 전 ICQA 공지로 한 번 더 확인)

| 항목 | 내용 |
|---|---|
| 주관 | 한국정보통신자격협회(ICQA) |
| 필기 형식 | 50문항, 4지 택일형, CBT |
| 시험 시간 | 50분 |
| 합격 기준 | 100점 만점 60점 이상 (= **50문항 중 30문항 이상 정답**) |
| 과목 | TCP/IP · 네트워크 일반 · NOS(Windows Server / Linux) · 네트워크 운용기기 |
| 체감 비중 | TCP/IP ≒ NOS > 네트워크 일반 ≒ 네트워크 운용기기 (보안 문제는 여러 과목에 섞여 출제) |

**합격 전략:** 60점만 넘기면 됩니다. 계산 문제(서브넷팅)와 포트 번호, 명령어처럼 **외우면 무조건 맞는 문제**를 확실히 챙기고, 처음 보는 문제는 과감히 찍고 넘어가세요.

### 각 노트의 구성 (모두 동일)
1. **본문** — 처음 보는 사람 기준으로 "왜 그런지"까지 설명, 각 절 끝에 `💡 시험 포인트`
2. **★ 핵심사항** — 시험 직전 10분 암기용
3. **⚠️ 헷갈리는 함정 포인트** — 오답 선지로 자주 나오는 비교쌍
4. **🧠 암기 팁** — 두문자/연상법
5. **📝 연습문제 25문항** — 과거 기출 빈출 유형 변형 (노트끼리 중복 없음)
6. **✅ 정답 및 해설** — 오답 선지가 왜 틀렸는지까지

> 연습문제는 **처음엔 정답을 가리고** 풀고, 틀린 문제는 문항 ID(예: `[IP-07]`)로 오답노트에 기록하세요.

## 4. CBT는 최근 몇 개년을 남겨둘까? → **최근 2개년(약 8회분) 추천**

네트워크관리사 2급은 **정기시험이 1년에 4회** 정도라서 2개년 ≒ 8회분입니다.

| 상황 | 남겨둘 회차 | 이유 |
|---|---|---|
| **기본(추천)** | **최근 2개년 ≒ 8회분** | 최근 출제 경향 + 반복 출제 문제를 충분히 체크하면서도, 1~2일 안에 다 풀 수 있는 양 |
| 시간이 정말 없을 때 | 최근 1개년 ≒ 4회분 | 최소한 최신 경향 확인용 |
| 시간이 넉넉할 때 | 최근 3개년 ≒ 12회분 | 3년차 회차는 "복습용"으로 빠르게 |

**이 노트의 연습문제·모의고사는 그보다 이전(대략 2010년대) 빈출 유형을 변형**한 것이라, CBT로 남겨둔 최근 회차를 미리 "스포"하지 않습니다.

### ⚠️ 사이트 3곳 사용 시 주의 — "회차 기준"으로 나누세요
comcbt · cbtbank · sqldpass는 **같은 ICQA 기출 회차를 각자 수록**하는 경우가 많아서, 사이트만 바꿔 같은 회차를 풀면 **중복**입니다. 사이트가 아니라 **회차(시행 연월)** 를 기준으로 배분하세요.

| 단계 | 회차 | 추천 사이트 사용법 |
|---|---|---|
| CBT 1차 (D-2) | 최근 8회 중 **오래된 쪽 4회** | comcbt의 CBT(실전) 모드로 50분 타이머 → 채점 후 해설 확인 |
| CBT 2차 (D-1) | 최근 8회 중 **최신 쪽 4회** | 아직 안 푼 회차를 cbtbank / sqldpass 등 다른 사이트 화면으로 풀어 실전 감각 유지 |
| 모의고사 (D-1 저녁) | [08_최종모의고사.md](08_최종모의고사.md) | 연습문제·CBT와 겹치지 않는 50문항 |
| 랜덤 모드 | 시험 당일 아침 | 사이트의 랜덤/오답 모드는 **이미 푼 회차의 오답 복습용**으로만 |

> **CBT 점수 해석:** 최근 회차 CBT에서 **70점 이상이 2회 연속**이면 합격권, 60점대면 오답 개념을 노트 본문으로 돌아가 보강하세요.
