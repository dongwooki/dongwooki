# 네트워크관리사 2급 실기 — 조사 결과 (2026년 11월 1일 기준)

> ICQA 공식 안내와 수험생 후기·정리 글을 폭넓게 검색해 모은 내용입니다. **공식 확인**과 **후기 기준**을 구분해 적었습니다. 후기 자료는 1~4년 전 글이 섞여 있어 세부 내용이 다를 수 있습니다.

---

## 1. 시험 정보 (공식)

| 항목 | 내용 |
|---|---|
| 시험 시간 | 80분 |
| 출제 형식 | 작업형, 서술(단답)형, 선택형 |
| 출제 범위 | LAN 전송매체, 네트워크 설계·구축, TCP/IP, NOS, 네트워크 운용기기 |
| 합격 기준 | 100점 만점에 60점 이상 |
| 응시 자격 | 2급 필기 합격일로부터 2년 이내 |
| 응시료 | 78,000원 |
| **2026년 제4회 실기** | **접수 11월 3일 ~ 6일 · 시험 12월 6일 · 발표 12월 15일** |
| 시험 지역 | 서울, 인천, 수원, 대전, 대구, 부산, 광주, 제주 |

- 시험장은 시험일 약 1주일 전에 접수 내역에서 확인할 수 있습니다(후기).

## 2. 문제 구성 (후기 기준)

| 구분 | 문항 | 배점 | 시간 |
|---|---|---|---|
| ① 케이블 제작 | 1문제 | 6.5점 | 약 10분 |
| ② 윈도우 서버 에뮬레이터 작업형 | 8~9문제 | 문항당 5.5점 | ②+③ 약 50분 |
| ③ 단답형·선택형 | 5~6문제 | 문항당 5.5점 | |
| ④ 라우터 명령어 | 3문제 | 문항당 5.5점 | 약 20분 |

- 총 18문제 안팎입니다. **케이블 6.5점 + 나머지 17문제 × 5.5점 = 100점**으로 계산이 맞습니다.
- 문제 유형이 십여 가지로 정해져 있어 기출 유형이 반복됩니다(나무위키·후기 공통).
- 60점이면 합격이므로, 케이블을 맞히면 나머지 17문제 중 **10문제(55점)** 이상을 맞히면 됩니다. 케이블을 틀리면 11문제가 필요합니다.

## 3. 유형별 출제 내용

### ① 케이블 제작
- 다이렉트 또는 크로스 중 하나를 실제 UTP 케이블로 만들어 10분 안에 제출합니다.
- T568B 배열: 주황흰 · 주황 · 초록흰 · 파랑 · 파랑흰 · 초록 · 갈색흰 · 갈색
- T568A 배열: B에서 주황 쌍과 초록 쌍의 자리를 바꾼 것(초록흰 · 초록 · 주황흰 · 파랑 · 파랑흰 · 주황 · 갈색흰 · 갈색)
- 다이렉트는 양쪽 모두 B, 크로스는 한쪽 A·한쪽 B입니다.
- 감점 기준(피복 길이, 압착 상태 등)은 공개된 자료를 찾지 못했습니다. 테스터로 8선이 모두 맞게 통하는지가 핵심입니다.
- 후기: 두 번째부터 8분 안에 끝낼 수 있었다고 합니다. 실물로 여러 번 연습하는 것이 가장 중요합니다.

### ② 윈도우 서버 에뮬레이터 작업형
시험장 프로그램은 실제 Windows Server 화면을 흉내 낸 에뮬레이터입니다. 후기에 나온 문제 유형은 다음과 같습니다.

| 유형 | 입력하는 내용 |
|---|---|
| TCP/IP 설정 | IPv4 속성에서 IP 주소, 서브넷 마스크, 기본 게이트웨이, 기본·보조 DNS |
| DNS 서버 | 관리 도구에서 DNS 서버 설정(영역, 레코드) |
| DHCP 범위 | 범위 이름, 설명, 시작·끝 주소, 서브넷 마스크, 제외 범위, 임대 기간, 게이트웨이(라우터) 옵션 |
| IIS 웹사이트 | 사이트 이름, 실제 경로, IP 주소, 포트(예: 8080), 특정 IP 액세스 거부, 기본 문서(index.html만 남기기) |
| FTP 사이트 | 사이트 이름, 실제 경로, IP·포트, 익명 사용자 읽기 전용, 특정 대역 접근 거부, 최대 연결 수(고급 설정), 연결 초과·접속 메시지(FTP 메시지) |
| 로컬 보안 정책 | 최소·최대 암호 사용 기간, 최소 암호 길이, 계정 잠금(예: 3회 실패 시 30분 잠금), 보안 옵션 |
| 사용자 계정 | 계정 만들기, 설정 |
| Hyper-V | 가상 컴퓨터 새로 만들기 |

- 후기 팁: 서버 이름을 먼저 설정한 뒤 네트워크를 설정하라는 순서 팁이 있습니다.
- 감점 사례로 IP 주소 설정을 빠뜨리는 실수가 언급됩니다.

### ③ 단답형·선택형
후기와 암기 카드에 나온 항목은 다음과 같습니다.
- **보안:** IDS(오용 탐지·이상 탐지), IPS(유해 트래픽을 능동적으로 차단), VPN, VPN 터널링 프로토콜(L2F, PPTP, L2TP, IPsec)
- **네트워크:** NAT, 포트 미러링(스위치 트래픽을 다른 포트로 복사, IDS 구축에 사용), 서브넷 계산
- **리눅스 명령어:** IP 확인(`ifconfig` / `ip addr`), 파일 찾기 `find`, 디스크 용량 `df`, 라우팅 테이블 `route`, 이름 조회 `nslookup`, 경로 추적 `traceroute`, 권한 변경 `chmod`

### ④ 라우터 명령어 (Cisco IOS 에뮬레이터)
후기에 나온 문제 유형은 다음과 같습니다.

| 유형 | 명령어 |
|---|---|
| 인터페이스 IP·활성화 | `interface FastEthernet 0/0` → `ip address 192.168.0.100 255.255.255.0` → `no shutdown` |
| 보조 IP | `ip address … secondary` |
| 대역폭·클럭 | `bandwidth 2048`, `clock rate 72000` |
| 원격 접속 암호 | `line vty 0 4` → `password icqa` → `login`, SSH 전환은 `transport input ssh` |
| DHCP 풀 | `ip dhcp pool icqa` → `network 192.168.100.0 255.255.255.0` (+ `default-router`, `dns-server`) |
| 게이트웨이·경로 | `ip default-gateway`, 정적 경로 `ip route`, RIP 환경의 기본 경로 `ip default-network` |
| OSPF | `router ospf 1` → `network 주소 와일드카드마스크 area 0` (와일드카드는 서브넷 마스크를 뒤집은 값) |
| 확인 명령 | `show interface`, `show ip route`, `show flash`, `show users`, `show running-config` |
| 저장 | `copy running-config startup-config` |

- 문제에서 **저장 명령을 지정하면 그 명령만 써야** 합니다. 다른 저장 명령은 사용 금지라는 조건이 붙기도 합니다.
- 후기 실수 사례: OSPF만 준비했다가 정적 라우팅 문제를 틀림, 저장을 빠뜨림, 철자 오타(`running-cofig`).
