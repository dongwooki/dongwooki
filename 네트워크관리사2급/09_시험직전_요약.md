# 09. 시험 직전 핵심 요약 (시험장 가기 전 15분)

> 각 노트의 ★ 핵심사항 가운데 **가장 자주 나오는 것만** 추렸습니다. 모르는 줄이 있으면 괄호 안의 노트 번호로 돌아가 복습하세요.

## 1. OSI 7계층 · 장비 · PDU (01, 06)

| 계층 | 핵심 기능 | PDU | 장비 / 프로토콜 |
|---|---|---|---|
| 7 응용 | 사용자 서비스 | 데이터 | HTTP, FTP, SMTP, DNS, SNMP, 게이트웨이 |
| 6 표현 | 암호화·압축·코드 변환 | 데이터 | JPEG, MPEG, ASCII |
| 5 세션 | 대화 제어, **동기점** | 데이터 | NetBIOS, RPC |
| 4 전송 | **종단 간** 신뢰성, 포트 | 세그먼트 | TCP, UDP, L4 스위치 |
| 3 네트워크 | **라우팅**, IP 주소 | 패킷 | IP, ICMP, IGMP, ARP*, 라우터, L3 스위치 |
| 2 데이터링크 | 프레임, MAC, **인접 노드** 오류·흐름 제어 | 프레임 | 브리지, L2 스위치, HDLC, PPP |
| 1 물리 | 비트 전송 | 비트 | 리피터, 허브, 케이블 |

- 충돌 도메인 분할: 브리지·스위치·라우터 / 브로드캐스트 도메인 분할: **라우터(L3)**, VLAN
- CSMA/CD = 유선 이더넷(802.3) · CSMA/CA = 무선(802.11, RTS/CTS) · 토큰 링 = 802.5
- 메시 회선 수 **n(n−1)/2**, 포트 수 n−1
- PCM: **표본화 → 양자화 → 부호화**, 나이퀴스트 = 최고 주파수 × 2
- bps = baud × 비트 수(log₂ 진수)
- Go-Back-N: 오류 프레임부터 전부 재전송 / Selective: 오류 프레임만
- 10Base-T 100m · 10Base2 185m · 10Base5 500m
- 802.11b 2.4GHz 11Mbps · a 5GHz 54 · g 2.4GHz 54 · n 600Mbps · ac 5GHz · ax(Wi-Fi 6)
- ATM 셀 53바이트(헤더 5+48) · ISDN BRI 2B+D 144kbps

## 2. IP 주소 · 서브넷팅 (02)

| 클래스 | 첫 옥텟 | 기본 마스크 | 사설 대역 |
|---|---|---|---|
| A | 1~126 | /8 | 10.0.0.0/8 |
| B | 128~191 | /16 | 172.16.0.0 ~ 172.31.255.255 |
| C | 192~223 | /24 | 192.168.0.0/16 |
| D | 224~239 | 멀티캐스트 | |
| E | 240~255 | 실험용 | |

- 루프백 127.0.0.1 · APIPA 169.254.0.0/16 · 제한 브로드캐스트 255.255.255.255
- **블록 크기 = 256 − 마스크 값** → 네트워크 = 블록 배수, 브로드캐스트 = 다음 블록 − 1
- 호스트 수 = **2ʰ − 2**, 서브넷 수 = 2ⁿ (빌린 비트)

| 마스크 끝 | 128 | 192 | 224 | 240 | 248 | 252 |
|---|---|---|---|---|---|---|
| 프리픽스(4옥텟) | /25 | /26 | /27 | /28 | /29 | /30 |
| 블록 | 128 | 64 | 32 | 16 | 8 | 4 |
| 호스트 | 126 | 62 | 30 | 14 | 6 | 2 |

- IPv4 헤더 20~60바이트, TTL 홉마다 −1, Protocol **1 ICMP / 2 IGMP / 6 TCP / 17 UDP**
- 단편화 필드: Identification · Flags(DF/MF) · Fragment Offset
- IPv6: 128비트, **:: 는 한 번만**, 브로드캐스트 없음(유니·멀티·애니캐스트), 헤더 40바이트 고정·체크섬 없음, 링크로컬 fe80::/10, 루프백 ::1
- IPv6 전환: 듀얼 스택 · 터널링 · 변환(NAT64)

## 3. 프로토콜 · 포트 · 라우팅 (03)

| 포트 | 서비스 | | 포트 | 서비스 |
|---|---|---|---|---|
| 20/21 | FTP (데이터/제어) | | 110 | POP3 |
| 22 | SSH | | 123 | NTP (UDP) |
| 23 | Telnet | | 143 | IMAP |
| 25 | SMTP | | 161/162 | SNMP (UDP, 162=Trap) |
| 53 | DNS | | 389 | LDAP |
| 67/68 | DHCP (UDP) | | 443 | HTTPS |
| 69 | TFTP (UDP) | | 3389 | RDP |
| 80 | HTTP | | 0~1023 | Well-known |

- ARP: IP→MAC (요청 브로드캐스트, 응답 유니캐스트) · RARP: MAC→IP
- ICMP: 0 Echo Reply · 3 Unreachable · 5 Redirect · 8 Echo Request · 11 Time Exceeded(tracert)
- TCP: 3-way **SYN → SYN+ACK → ACK**, 헤더 20바이트 / UDP 헤더 8바이트(4필드)
- DHCP **DORA** (Discover → Offer → Request → Ack)
- DNS: A(IPv4) · AAAA(IPv6) · CNAME(별칭) · MX(메일) · NS · PTR(역방향) · SOA
- RIP: 거리 벡터, 벨만-포드, **최대 15홉**, 30초 · OSPF: 링크 상태, 다익스트라, Area 0 · EIGRP: 시스코, DUAL · BGP: AS 간(EGP)
- AD: 직접 연결 0 · 정적 1 · EIGRP 90 · OSPF 110 · RIP 120 (작을수록 우선)
- 명령어: `ipconfig /all /release /renew /flushdns` · `netstat -a -n -r(라우팅) -s(통계)` · `tracert` · `pathping` · `nslookup` · `arp -a` · `route print`

## 4. Windows Server (04)

- AD 구조: 포리스트 ⊃ 트리 ⊃ 도메인 ⊃ OU · GPO 적용 순서 **L → S → D → OU**(나중 것이 이김)
- FSMO 포리스트 단위: **스키마 · 도메인 명명** / 도메인 단위: RID · PDC 에뮬레이터 · 인프라
- 그룹 범위: 도메인 로컬 · 글로벌 · 유니버설 → **AGDLP**
- NTFS 권한: 누적, **거부 우선** / 공유 + NTFS = **더 제한적인 것**
- 같은 볼륨 **이동**만 권한 유지, 나머지(복사, 다른 볼륨 이동)는 대상 폴더 권한 상속
- 숨김 공유 **$** · FAT32 파일 4GB 제한 · EFS(파일 단위, NTFS) vs BitLocker(볼륨 전체, TPM)
- 볼륨 내결함성: **미러(RAID 1), RAID-5**만 / RAID-5 용량 (n−1)×D
- MBR 주 파티션 4개·2TB / GPT 128개·2TB 초과·UEFI
- DHCP: 예약(MAC 고정) · 제외 · 릴레이 에이전트 / DNS: 주 · 보조(읽기 전용) · 스텁
- msc: dsa(AD 사용자) · gpmc · gpedit · diskmgmt · compmgmt · services · eventvwr · lusrmgr · secpol
- 이벤트 뷰어 로그온 감사 = **보안 로그** · `gpupdate /force`

## 5. Linux (05)

- 권한: r4 w2 x1 · SetUID 4 / SetGID 2 / Sticky 1(t, /tmp) · umask: 파일 666−, 디렉터리 777−
- /etc/passwd = `이름:x:UID:GID:설명:홈:셸` · 암호는 /etc/shadow · 기본 환경 파일 /etc/skel
- kill: **1 HUP · 9 KILL(강제) · 15 TERM(기본)** · nice −20(높음) ~ 19(낮음)
- 런레벨 0 종료 · 1 단일 · 3 텍스트 다중(multi-user.target) · 5 GUI(graphical) · 6 재부팅
- `systemctl start(지금) / enable(부팅 시)` · `rpm -ivh 설치 -e 삭제 -qa 목록` · Red Hat=yum/dnf, Debian/Ubuntu=apt
- fstab 6필드: 장치 · 마운트포인트 · 종류 · 옵션 · dump · fsck
- `tar -cvf 묶기 / -xvf 풀기 / z=gzip` · vi `:wq 저장종료 :q! 강제종료 dd 줄삭제 yy 복사`
- crontab: **분 시 일 월 요일**(0=일요일) · `>` 덮어쓰기 `>>` 추가
- /etc/resolv.conf(DNS 서버) · /etc/hosts(이름↔IP) · named.conf(BIND) · smb.conf(Samba) · /etc/exports(NFS)

## 6. 운용기기 (06)

- 스위치: Learning(**출발지 MAC**) · Flooding · Forwarding · Filtering · Aging
- 스위칭: Store-and-Forward(전체 저장·CRC) · Cut-Through(목적지 MAC만, 가장 빠름) · Fragment-Free(64바이트)
- 이더넷 프레임 64~1518바이트, 데이터 46~1500
- VLAN 간 통신 = 라우터/L3 스위치 · 802.1Q 태그 4바이트, VID 12비트, Native VLAN은 태그 없음
- STP 802.1D: 루트 브리지 = **가장 낮은 BID**(우선순위 32768 먼저 비교) · Blocking→Listening→Learning→Forwarding · Hello 2 / Max Age 20 / Forward Delay 15초 · RSTP 802.1w
- LACP 802.3ad · PoE 802.3af/at · VRRP(표준) / HSRP·GLBP(시스코)
- 같은 종류 장비끼리 = 크로스오버 · 콘솔 = 롤오버
- 라우터 메모리: ROM(POST·부트스트랩) · Flash(IOS) · NVRAM(startup-config) · RAM(running-config)
- `copy running-config startup-config` · `ip route 목적지 마스크 다음홉` (전역 설정 모드)
- RAID 0(스트라이핑, 내결함성 X) · 1(미러, 50%) · 5(최소 3, 패리티 1) · 6(최소 4, 패리티 2) · 10(최소 4, 50%)
- DAS(직접) · NAS(LAN, **파일** 단위) · SAN(전용망, **블록** 단위)

## 7. 보안 (07)

- 가로막기 → 가용성 · 가로채기 → 기밀성 · 변조 → 무결성 · 위조 → 인증
- 웜(독립·자기 복제) · 바이러스(숙주 필요) · 트로이 목마(위장, 복제 X) · 랜섬웨어(암호화 후 금전 요구)
- SYN Flooding(Half-Open) · **Smurf**(ICMP + 브로드캐스트) · **Land**(출발지 = 목적지) · Teardrop(오프셋) · Ping of Death(65,535 초과)
- 파밍(DNS/hosts 변조) · 피싱(가짜 링크) · 스미싱(SMS) · SQL Injection(`' OR '1'='1`) · XSS(스크립트) · CSRF(사용자 권한 도용)
- 방화벽: 패킷 필터링 · 상태 검사 · 애플리케이션 게이트웨이(프록시) · 스크린드 서브넷(DMZ, 가장 안전)
- IDS 오용(시그니처, 신종 X) vs 이상(행위, 신종 O, 오탐 ↑) · IPS = 탐지 + 차단
- IPSec: **AH = 인증·무결성(암호화 X)**, **ESP = 암호화 O** · 전송 모드 vs 터널 모드
- 대칭: DES(56) · AES · SEED · ARIA · 키 개수 n(n−1)/2 / 비대칭: RSA · ECC · 키 개수 2n
- 전자서명 = **송신자 개인키**로 서명 · 기밀성 암호화 = 수신자 공개키
- Kerberos(티켓, KDC) · RADIUS(UDP) · TACACS+(TCP) · WEP(취약) < WPA(TKIP) < WPA2(AES-CCMP) < WPA3(SAE)

## 🎯 시험장 전략
1. **1회독(30분):** 아는 문제부터 빠르게 푼다. 계산 문제와 지문이 긴 문제는 표시만 하고 넘어간다.
2. **2회독(15분):** 표시한 문제로 돌아간다. 서브넷팅은 블록 크기로 계산한다.
3. **마지막 5분:** 빈칸 없이 모두 답을 고른다. 틀려도 감점이 없으니 모르는 문제도 반드시 찍는다.
4. "옳지 **않은** 것"을 묻는 문제는 보기마다 O/X를 표시하며 푼다.
